# Домашние задания Аси

Репозиторий содержит учебные Jupyter-ноутбуки по Python и математической статистике.

## Структура

```text
hw_asya/
├── python/
│   ├── tasks_2026-08-20.ipynb
│   └── tasks_2026-08-22_iterables.ipynb
├── matstat/
│   ├── week01_homework.ipynb
│   ├── logo.png
│   └── data/
│       └── youtube_data_short.csv
├── requirements.txt
└── README.md
```

- `python/` — задания по основам Python, функциям, условиям, циклам и итерируемым объектам.
- `matstat/` — альтернативная домашняя работа по темам первой недели: описательные статистики, группировки, визуализация и симуляции.

## Статус домашних заданий

- ✅ `python/tasks_2026-08-20.ipynb` — домашняя работа по основам Python выполнена.
- ✅ `python/tasks_2026-08-22_iterables.ipynb` — домашняя работа по итерируемым объектам выполнена.
- ⬜ `matstat/week01_homework.ipynb` — 10 новых заданий первой недели подготовлены для самостоятельного выполнения.

## Короткий порядок работы

1. Скачайте репозиторий и установите окружение.
2. Перед новой домашней работой обновите `main` и создайте от неё отдельную ветку.
3. Выполните и проверьте ноутбук.
4. Закоммитьте только относящиеся к заданию файлы и отправьте свою ветку в GitHub.
5. Создайте Pull Request из своей ветки в `main`.

## Как скачать проект

Установите [Python](https://www.python.org/downloads/) версии 3.10 или новее и Git. Затем откройте терминал и выполните:

```bash
git clone https://github.com/tlum1/hw_asya.git
cd hw_asya
```

Если проект уже скачан, для получения последних изменений выполните:

```bash
cd hw_asya
git switch main
git pull --ff-only origin main
```

## Как создать окружение

Создайте виртуальное окружение в корне проекта:

```bash
python3 -m venv .venv
```

Активируйте его на macOS или Linux:

```bash
source .venv/bin/activate
```

На Windows в PowerShell используйте:

```powershell
.venv\Scripts\Activate.ps1
```

После активации обновите `pip` и установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Как начать новую домашнюю работу

Каждую домашнюю работу нужно выполнять в отдельной ветке. Не вносите учебные изменения непосредственно в `main`.

Сначала перейдите в корень репозитория, обновите `main` и создайте новую ветку:

```bash
cd hw_asya
git switch main
git pull --ff-only origin main
git switch -c homework/asya-matstat-week01
```

В примере ветка называется `homework/asya-matstat-week01`. Для другого задания замените последнюю часть на короткое понятное название. Используйте латинские буквы, цифры и дефисы, без пробелов. Например:

```text
homework/asya-python-functions
homework/asya-python-iterables
homework/asya-matstat-week02
```

Проверьте, что находитесь в нужной ветке:

```bash
git branch --show-current
```

## Как открыть ноутбуки в VS Code

Установите [Visual Studio Code](https://code.visualstudio.com/) и два официальных расширения:

- [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python);
- [Jupyter](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter).

Расширения можно установить через раздел **Extensions** в VS Code или командами в терминале:

```bash
code --install-extension ms-python.python
code --install-extension ms-toolsai.jupyter
```

Откройте **всю корневую папку репозитория**, а не отдельный файл. Из папки `hw_asya` выполните:

```bash
code .
```

Если команда `code` недоступна, откройте VS Code вручную, выберите **File → Open Folder** и укажите папку `hw_asya`.

В панели **Explorer** слева откройте нужный ноутбук:

- `python/` — домашние задания по Python;
- `matstat/week01_homework.ipynb` — домашняя работа по математической статистике.

После открытия ноутбука нажмите **Select Kernel** в правом верхнем углу, затем выберите **Python Environments** и интерпретатор из папки `.venv`:

- macOS/Linux: `.venv/bin/python`;
- Windows: `.venv\Scripts\python.exe`.

Если `.venv` не отображается, откройте палитру команд сочетанием `Cmd+Shift+P` на macOS или `Ctrl+Shift+P` на Windows/Linux, выполните **Python: Select Interpreter** и выберите интерпретатор вручную. После этого снова нажмите **Select Kernel** в ноутбуке.

Для запуска одной ячейки нажмите кнопку ▶ слева от неё или используйте `Shift+Enter`. Для проверки всего ноутбука выберите **Restart** и затем **Run All** на панели ноутбука. Все ячейки должны выполниться сверху вниз без ошибок.

Для ноутбука по математической статистике важно сохранить структуру папки `matstat/`: файл данных загружается по относительному пути `data/youtube_data_short.csv`.

После окончания работы сохраните ноутбук сочетанием `Cmd+S` на macOS или `Ctrl+S` на Windows/Linux. Если виртуальное окружение было активировано в терминале вручную, деактивируйте его:

```bash
deactivate
```

## Как сдать домашнюю работу через Pull Request

### 1. Проверьте ноутбук

Перед отправкой сохраните ноутбук в VS Code, нажмите **Restart**, а затем **Run All** на панели ноутбука. Все ячейки должны выполниться сверху вниз без ошибок.

Проверьте список изменённых файлов:

```bash
git status
git diff --stat
```

В списке не должно быть `.venv`, паролей, токенов, временных файлов или изменений, не относящихся к домашней работе.

### 2. Добавьте файлы и создайте коммит

Добавляйте конкретный файл с домашней работой. Например, для первой недели матстата:

```bash
git add matstat/week01_homework.ipynb
git diff --cached --stat
git commit -m "Complete statistics homework week 01"
```

Если для задания были добавлены необходимые данные или другие файлы, перечислите их в команде `git add` через пробел. Не используйте `git add .`, если не уверены, что все изменения относятся к заданию.

### 3. Отправьте свою ветку в GitHub

Замените имя ветки в команде на своё:

```bash
git push -u origin homework/asya-matstat-week01
```

Последующие коммиты в ту же ветку можно отправлять короткой командой:

```bash
git push
```

### 4. Создайте Pull Request

Pull Request нужно создавать **из своей ветки в `main`**:

- `base` — `main`;
- `compare` — ваша ветка, например `homework/asya-matstat-week01`.

На сайте GitHub откройте репозиторий после `git push`, нажмите **Compare & pull request**, проверьте ветки, заполните название и описание, затем нажмите **Create pull request**.

Если установлен [GitHub CLI](https://cli.github.com/), при первом использовании авторизуйтесь, а затем откройте форму создания PR:

```bash
gh auth login
gh pr create --web --base main --head homework/asya-matstat-week01
```

Название PR должно коротко объяснять, какое задание выполнено. Например:

```text
Выполнить домашнюю работу по матстату за неделю 1
```

В описание PR добавьте:

```markdown
## Что сделано

- Выполнены задания первой недели.
- Добавлены необходимые расчёты и графики.

## Как проверено

- [x] Ноутбук выполнен целиком сверху вниз.
- [x] Все ячейки выполняются без ошибок.
- [x] В PR нет лишних файлов.

## Вопросы

Нет вопросов.
```

Если есть вопросы или сомнения по решению, перечислите их в разделе «Вопросы» вместо фразы «Нет вопросов».

### 5. Проверьте PR перед сдачей

Перед отправкой ссылки на проверку убедитесь, что:

- PR открыт в `main`, а не в другую учебную ветку;
- в PR находится только одна домашняя работа;
- вкладка **Files changed** не содержит `.venv`, секретов и посторонних файлов;
- ноутбук сохранён с актуальными результатами выполнения;
- название и описание PR заполнены;
- PR не закрыт и не переведён в Draft, если работа уже готова к проверке.

Если после создания PR нужно что-то исправить, внесите изменения в **ту же ветку**, создайте новый коммит и выполните `git push`. Создавать новый PR не нужно — он обновится автоматически.

## Правила сдачи

- Одна домашняя работа — одна отдельная ветка и один PR.
- Новая ветка создаётся от актуальной ветки `main`.
- Нельзя отправлять решения напрямую в `main`.
- Не изменяйте файлы других домашних работ без необходимости.
- Не добавляйте в Git виртуальное окружение `.venv`, пароли, токены и системные файлы.
- Перед сдачей ноутбук должен выполняться целиком без ошибок.
- Для исправлений после проверки продолжайте использовать исходную ветку и PR.
